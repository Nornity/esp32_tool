# Tricorder — ESP32-C3 SuperMini

Прошивка для ESP32-C3 SuperMini с OLED 128×64, тремя кнопками, аккумулятором и ИК-светодиодом. Основной скетч: [`sketch_nov7a.ino`](sketch_nov7a.ino).

## Подключения в скетче

Пины заданы в начале `.ino`; если ваша ревизия платы или разводка отличается, поменяйте определения и проверьте их до подачи питания.

| Узел | GPIO | Примечание |
|---|---:|---|
| OLED SDA | 8 | I²C, адрес дисплея `0x3C` |
| OLED SCL | 9 | I²C, 400 кГц |
| Кнопка LEFT | 2 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| Кнопка RIGHT | 3 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| Кнопка SELECT | 4 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| ИК-светодиод / драйвер | 0 | Управляющий выход; нужен транзисторный ключ с токоограничением |
| Измерение батареи | 1 | ADC через подходящий делитель напряжения |

**Не подключайте Li-ion аккумулятор напрямую к GPIO1.** Проверьте схему делителя, пределы ADC и калибровку `BATT_CAL_DEF` для своей платы. Зарядка и защита аккумулятора должны обеспечиваться отдельной подходящей схемой.

## Сборка

1. Установите Arduino IDE и поддержку плат ESP32 от Espressif.
2. Выберите плату ESP32-C3 и проверьте параметры USB/CDC и разделов Flash для своей версии платы.
3. Установите библиотеки **Adafruit GFX Library**, **Adafruit SSD1306** и **IRremoteESP8266**; `qrcode.h` должен быть доступен в include path.
4. Откройте `sketch_nov7a.ino`, проверьте распиновку и соберите/загрузите скетч.

Скетч использует Wi‑Fi для сетевых тестов, NTP и пассивного анализа эфира. Результаты сетевых тестов зависят от доступности внешних узлов. Используйте радио-функции только в сетях и среде, на которые у вас есть разрешение.

## Новые возможности

- История напряжения аккумулятора хранится в версионированном формате с CRC и восстановлением из временного файла после прерванной записи; старый формат графика мигрирует при загрузке.
- При заряде ≤15% меню и экран батареи показывают предупреждение. OLED автоматически выключается после 90 секунд бездействия в главном меню (после 30 секунд при ≤10%); нажатие любой кнопки включает экран. Пока экран выключен, опрос батареи реже.
- В `Proj`/`TV` на экране ИК-клавиш удерживайте RIGHT, чтобы добавить выбранную команду в избранное. До 8 команд доступны через `Tools → IR Fav`; короткое SELECT отправляет команду, удержание LEFT удаляет слот. В макросах SELECT останавливает воспроизведение. Обучение новых кодов не реализовано: для него нужен ИК-приёмник, которого нет в указанной схеме.
- `WiFi → Analyze → Signal` показывает RSSI выбранной сети и историю до 12 замеров. SELECT выводит CSV в Serial (`115200` бод). В `WiFi → Channels` отображается относительная оценка загруженности 2.4 ГГц по числу и силе сигналов точек доступа; это не измерение airtime/занятости канала.

## Serial-помощник

`esp32_tool.py` — отдельный необязательный Python-инструмент для просмотра serial-лога и отправки текстовых данных. Установка:

```bash
python -m pip install pyserial
```

Примеры:

```bash
python esp32_tool.py ports
python esp32_tool.py monitor --port COM3
python esp32_tool.py monitor -p /dev/ttyUSB0 --timestamps
python esp32_tool.py send -p COM3 "HELLO"
```
