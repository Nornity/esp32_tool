# esp32_tool

Небольшой кроссплатформенный помощник для работы с ESP32 через последовательный порт: показывает доступные порты, выводит serial-лог и отправляет текстовые команды.

## Установка

Нужен Python 3.10 или новее. Установите единственную зависимость:

```bash
python -m pip install pyserial
```

Скачивать и прошивать прошивку утилита не пытается — для этого используйте ESP-IDF или Arduino IDE.

## Использование

```bash
python esp32_tool.py ports
python esp32_tool.py monitor --port COM3
python esp32_tool.py monitor -p /dev/ttyUSB0 --baud 115200 --timestamps
python esp32_tool.py send -p COM3 "LED ON"
```

Если подключён ровно один последовательный порт, `--port` можно не указывать. Для остановки монитора нажмите `Ctrl+C`. Команда `send` добавляет перевод строки автоматически; используйте `--no-newline`, если он не нужен. Скорость по умолчанию — 115200 бод.

В Linux доступ к порту может требовать членства в группе `dialout` и повторного входа в систему. Закройте Serial Monitor в Arduino IDE или другой программе, если порт уже занят.
