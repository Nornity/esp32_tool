# Tricorder — ESP32-C3 SuperMini

Прошивка для ESP32-C3 SuperMini с OLED 128×64, тремя кнопками, аккумулятором и ИК-светодиодом. Основной скетч: [`sketch_nov7a.ino`](sketch_nov7a.ino). Полный исходный код проекта одним архивом: [`tricorder_source.zip`](tricorder_source.zip).

## Подключения в скетче

Пины заданы в начале `.ino`; если ваша ревизия платы или разводка отличается, поменяйте определения и проверьте их до подачи питания.

| Узел | GPIO | Примечание |
|---|---:|---|
| OLED SDA | 8 | I²C, адрес дисплея `0x3C` |
| OLED SCL | 9 | I²C, 400 кГц |
| Кнопка LEFT | 2 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| Кнопка RIGHT | 3 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| Кнопка SELECT | 4 | Кнопка между GPIO и GND, `INPUT_PULLUP` |
| ИК-светодиод / драйвер | 0 | Управляющий выход; нужен транзисторный ключ с токоограничением |
| Измерение батареи | 1 | ADC через подходящий делитель напряжения |

**Не подключайте Li-ion аккумулятор напрямую к GPIO1.** Проверьте схему делителя, пределы ADC и калибровку `BATT_CAL_DEF` для своей платы. Зарядка и защита аккумулятора должны обеспечиваться отдельной подходящей схемой.

## Сборка

1. Установите Arduino IDE и поддержку плат ESP32 от Espressif.
2. Выберите плату ESP32-C3 и проверьте параметры USB/CDC и разделов Flash для своей версии платы.
3. Установите библиотеки **Adafruit GFX Library**, **Adafruit SSD1306** и **IRremoteESP8266**; `qrcode.h` должен быть доступен в include path.
4. Откройте `sketch_nov7a.ino`, проверьте распиновку и соберите/загрузите скетч.

Скетч использует Wi‑Fi для сетевых тестов, NTP и пассивного анализа эфира. Результаты сетевых тестов зависят от доступности внешних узлов. Используйте радио-функции только в сетях и среде, на которые у вас есть разрешение.

## Новые возможности

- История напряжения аккумулятора хранится в версионированном формате с CRC и восстановлением из временного файла после прерванной записи; старый формат графика мигрирует при загрузке.
- При заряде ≤15% меню и экран батареи показывают предупреждение. OLED гаснет после 90 секунд бездействия в главном меню (через 30 секунд при ≤10%); нажатие любой кнопки включает его. После 2 минут общего бездействия в главном меню ESP32 переходит в deep sleep, а любая из трёх кнопок будит его с новой загрузкой. Пока погашен только OLED, батарея опрашивается реже. Deep sleep снижает, но не обнуляет ток платы.
- В `Proj`/`TV` на экране ИК-клавиш удерживайте RIGHT, чтобы добавить выбранную команду в избранное. До 8 команд доступны через `Tools → IR Fav`; короткое SELECT отправляет команду, удержание LEFT удаляет слот. В макросах SELECT останавливает воспроизведение. Обучение новых кодов не реализовано: для него нужен ИК-приёмник, которого нет в указанной схеме.
- `WiFi → Analyze → Signal` показывает RSSI выбранной сети и историю до 12 замеров. SELECT выводит CSV в Serial (`115200` бод). В `WiFi → Channels` отображается относительная оценка загруженности 2.4 ГГц по числу и силе сигналов точек доступа; это не измерение airtime/занятости канала.
- `Tools → AI Chat` поднимает локальную Wi‑Fi точку `Tricorder-Chat` с паролем, показанным на OLED. Подключитесь к ней с телефона и откройте `http://192.168.4.1`. Чат использует гибрид из MLP-маршрутизатора тем и символьной RNN с 96 скрытыми состояниями. Квантованные int8-веса занимают примерно 241 КиБ суммарно. Классификатор задаёт тему, а RNN предсказывает следующий символ и генерирует ответ; готовая строка не выбирается в прошивке из таблицы. Это экспериментальный генератор, не полноценная полезная LLM: его обучающий корпус мал и ограничен функциями устройства, поэтому свободные ответы и понимание произвольных вопросов ожидать нельзя. Удержание SELECT выключает точку доступа.
- Переобучить веса можно командами `python -m venv .venv`, затем `.venv/bin/pip install numpy`, `.venv/bin/python train_tiny_intent.py` и `.venv/bin/python train_tiny_chat.py`; скрипты создают `tiny_chat_intent.h` и `tiny_chat_model.h` из корпуса `chat_corpus.py`. Увеличить качество одной только архитектурой нельзя: для полезной LLM нужны гораздо больше обучающих данных, Flash и RAM, чем есть у ESP32-C3.
- `Games` содержит классическую подборку для OLED: Snake, Tetris, Arkanoid, Pong, Space Invaders, Asteroids, Pac Maze, Frogger, Doodle Jump, Flappy, Lunar Lander, Galaga, Breakout, Missile Command, Racing и Minesweeper. Подсказки управления показаны в каждой игре. В Tetris LEFT/RIGHT двигают фигуру, SELECT вращает, удержание LEFT ставит паузу, удержание RIGHT бросает фигуру вниз. В Pac Maze и Frogger короткие LEFT/RIGHT двигают в стороны, удержания — вверх/вниз. Остальные игры выходят удержанием SELECT; в Minesweeper короткие LEFT/RIGHT двигают по строке, удержания — по вертикали, SELECT открывает клетку, удержание SELECT ставит флаг, LEFT+RIGHT вместе выходят. Только Pong замедлен ограничением симуляции в 25 кадров/с; темп остальных аркад не менялся. Графика игр оформлена контрастными HUD-панелями и более детальными спрайтами, аренами и фонами.
- Меню переработано в компактный вертикальный список с подсветкой выбранного пункта, видимыми соседними пунктами и подсказками управления; заголовок сохраняет счётчик, часы и зарезервированное место для батареи.
- В меню счётчик пунктов размещается перед батареей, а часы скрываются только если заголовок не помещается; индикатор батареи зарезервирован и остаётся виден.

## Serial-помощник

`esp32_tool.py` — отдельный необязательный Python-инструмент для просмотра serial-лога и отправки текстовых данных. Установка:

```bash
python -m pip install pyserial
```

Примеры:

```bash
python esp32_tool.py ports
python esp32_tool.py monitor --port COM3
python esp32_tool.py monitor -p /dev/ttyUSB0 --timestamps
python esp32_tool.py send -p COM3 "HELLO"
```
